01 / හැඳින්වීම

ජාල ආරක්ෂාව අවශ්‍ය ඇයි?

අන්තර්ජාලය හරහා පණිවිඩයක් යවන විට එය අතරමැදි ජාල හා උපාංග හරහා ගමන් කළ හැකිය. එබැවින් තොරතුරු අනිසි ලෙස කියවීම, වෙනස් කිරීම හෝ ව්‍යාජ ලෙස යැවීම වැළැක්වීමට ආරක්ෂණ ක්‍රම අවශ්‍ය වේ.

  • රහස්‍යතාව (Confidentiality): අවසර ලත් පාර්ශ්වයන්ට පමණක් දත්ත කියවිය හැකි වීම.
  • අඛණ්ඩතාව (Integrity): දත්ත අනවසරයෙන් වෙනස් වී නැති බව හඳුනාගත හැකි වීම.
  • සත්‍යාපනය (Authentication): සන්නිවේදනය කරන පාර්ශ්වය කවුරුන්දැයි තහවුරු කිරීම.
  • ලබාගත හැකි බව (Availability): අවශ්‍ය විට සේවාවට ප්‍රවේශ විය හැකි වීම.
02 / Threats

ජාලයකට එල්ල විය හැකි ප්‍රහාර

ප්‍රහාරකයකුට දත්ත ගමන් කරන අතරතුර ඒවා නිරීක්ෂණය කිරීමට, වෙනස් කිරීමට හෝ සන්නිවේදනය අඩාල කිරීමට උත්සාහ කළ හැකිය.

අන්තර්ක්‍රියාකාරී නිදසුන

03 / Cryptography

සංකේතනය මඟින් දත්ත ආරක්ෂා කිරීම

සංකේතනය (Encryption) යනු කියවිය හැකි දත්ත, යතුරක් නොමැතිව පහසුවෙන් තේරුම්ගත නොහැකි ආකාරයකට පරිවර්තනය කිරීමයි. නිවැරදි යතුර භාවිතයෙන් ලබන්නාට ඒවා නැවත කියවිය හැකිය.

සමමිතික යතුරු (Symmetric-key): සංකේතනයට සහ විකේතනයට එකම රහස් යතුරක් භාවිත වේ. පොදු යතුරු (Public-key): පොදු යතුරක් සහ පෞද්ගලික යතුරක් යුගලයක් භාවිත වේ.

සංකේතන අදහස අත්හදා බලන්න

මෙය ඉගෙනීම සඳහා පමණක් ඇති Caesar shift නිදසුනකි. සැබෑ ආරක්ෂක සංකේතනයක් නොවේ.

04 / Integrity

දත්ත වෙනස් වී තිබේද?

Hash function එකක් දත්තයකින් නියත දිගක සාරාංශයක් ලබා දෙයි. ආරක්ෂිත hash ක්‍රමයක් (උදා: SHA-256) භාවිත කරන විට කුඩා වෙනසක් වුවත් ප්‍රතිඵලය සැලකිය යුතු ලෙස වෙනස් විය හැකිය. Hash එකක් පමණක් ප්‍රභවය සත්‍යාපනය නොකරයි; ඒ සඳහා MAC හෝ ඩිජිටල් අත්සන් වැනි ක්‍රම අවශ්‍ය විය හැකිය.

SHA-256 වෙනස බලන්න

පණිවිඩයක් ඇතුළත් කර බොත්තම ඔබන්න.

මෙම අංගය browser එකේ Web Crypto API ලබා ගත හැකි විට ක්‍රියා කරයි.

05 / Authentication

අනිත් පාර්ශ්වය ඇත්තටම කවුද?

නමක් හෝ ලිපිනයක් පමණක් දැක පාර්ශ්වයක අනන්‍යතාව තහවුරු කළ නොහැක. Challenge–response ක්‍රමයකදී සත්‍යාපකයා අලුත් අභියෝගයක් යවයි. නිවැරදි රහස් යතුර හෝ පුද්ගලික යතුර ඇති පාර්ශ්වයට එයට අදාළ ප්‍රතිචාරයක් ලබා දිය හැකිය.

Challenge–response සංකල්පය

අභියෝගය ලබා ගැනීමට පහත බොත්තම ඔබන්න.
මෙය සංකල්පය පෙන්වන අනුකරණයකි; සැබෑ සත්‍යාපන පද්ධතියක් නොවේ.
06 / Secure communication

HTTPS සහ TLS

TLS (Transport Layer Security) යනු සේවාදායකය සහ පාරිභෝගිකයා අතර සන්නිවේදනය ආරක්ෂා කරන ප්‍රොටෝකෝලයකි. HTTPS, HTTP සන්නිවේදනය TLS හරහා යොදා ගනී. සාමාන්‍යයෙන් සහතිකයක් මගින් වෙබ් අඩවියේ සේවාදායකය සත්‍යාපනය කර, ආරක්ෂිත යතුරු එකඟතාවකින් සැසි යතුරු සකසා, පසුකාලීන දත්ත සංකේතනය කරයි.

07 / Network defense

ෆයර්වෝල් සහ ජාල ආරක්ෂණය

Firewall එකක් නියමිත ප්‍රතිපත්ති අනුව ජාල ගමනාගමනයට ඉඩ දීම හෝ අවහිර කිරීම සිදු කරයි. IDS/IPS පද්ධති සැක සහිත රටා හඳුනා ගැනීමට හෝ වැළැක්වීමට උපකාරී වේ. නිරන්තර යාවත්කාලීන කිරීම්, අවම අවසර සහ බහු-සාධක සත්‍යාපනයද වැදගත් වේ.

සරල Firewall නියමයක්

නිදසුන: වෙබ් සේවාව සඳහා TCP port 443 පමණක් විවෘත කර ඇත.

පෝර්ට් එකක් තෝරන්න.
