The last hop: what the link layer does

Hosts and routers are nodes. The wire or radio between two neighbours is a link. The link layer moves one frame across one link.

Node

A post office or a house

Any host or router. Mail stops at each one on the way.

Link

The road between neighbours

Wired (Ethernet) or wireless (WiFi). Each road can use a different kind of carrier.

Frame

The local delivery envelope

The IP datagram is the letter. The frame is the outer envelope that only lasts for one hop.

Services a link layer may offer

Framing

Put the datagram in an envelope with a header and trailer. MAC addresses in the header name the sender and receiver on this link.

Link access

On a shared road, a MAC protocol decides who may drive when.

Reliable delivery

Resend lost frames between neighbours. Rare on fiber or copper, common on wireless where errors are frequent.

Flow control

Don't stuff the neighbour's mailbox faster than they can empty it.

Error detection & correction

Noise and weak signals smudge bits. Detect it and drop or resend, or even fix it on the spot.

Half / full duplex

Half duplex: both ends can talk, but not at the same time. Full duplex: both at once.

Where does it live? In every host's network interface card (NIC) or on a chip. It is the building's own mailroom: hardware, software and firmware that attach to the host's bus and handle both the link and physical layers.

Tamper checks: error detection and correction

Rain on the road (noise, attenuation) can smudge bits. The sender adds extra check bits, called EDC, so the receiver can spot damage. It is never 100% sure, but more check bits catch more.

Two-dimensional parity: find and fix

Lab

Data sits in a 4×4 grid with a parity bit for every row and column (yellow). Flip one bit in transit, then the receiver finds the row and column that disagree. Their crossing is the bad bit, so it can be fixed with no resend.

You can also tap any data bit to smudge it yourself.

All rows and columns check out.
Internet checksum (review from ch. 3)

Treat the segment as 16-bit numbers, add them with one's complement, and put the result in the checksum field. The receiver redoes the sum. Cheap, but weaker than CRC.

CRC: the strong seal

Pick a generator G of r+1 bits. The sender appends r bits R so that <D,R> divides exactly by G using mod-2 math (XOR). Catches every burst error shorter than r+1 bits. Used by Ethernet and WiFi.

CRC calculator

Lab

Append r zeros to D, divide by G with XOR, and the remainder is R. The textbook example is filled in: D = 101110, G = 1001.

Sharing the road: multiple access protocols
Some links are point-to-point (one private driveway). Others are broadcast: one shared road for everyone, like WiFi, old Ethernet or cable upstream. If two carriers drive onto it at once, letters crash: a collision.


  
The tricky part: carriers must agree who goes next, but the only way to talk is the same shared road. There is no side channel. The ideal protocol gives one sender the full rate R, gives M senders R/M each, needs no boss and no shared clock, and stays simple.


  

    
Channel partitioning
Everyone gets a slice
TDMA: each carrier owns a time slot every round. FDMA: each owns a frequency lane. Fair under heavy load, wasteful when most are idle.

    
Random access
Just go, and retry on crashes
Send at full speed. Detect collisions and retry later. ALOHA, slotted ALOHA, CSMA, CSMA/CD (Ethernet), CSMA/CA (WiFi).

    
Taking turns
Pass the mailbag
Polling: a dispatcher invites each carrier in turn (Bluetooth). Token passing: only the holder of the token may send. Overhead, latency, single point of failure.

Slotted ALOHA
Fixed slots, synced clocks. On a crash, retry each later slot with probability p. Best case efficiency is 1/e ≈ 37%. Pure ALOHA (no slots) only reaches 1/(2e) ≈ 18%, since a frame can clash with anything sent one frame-time before or after.

    
CSMA and CSMA/CD
Listen before you knock: if the road is busy, wait. Collisions still happen because of propagation delay: two carriers may not yet hear each other. CD adds "stop talking when you hear a crash", which wastes less time. Easy on wires, hard on wireless.

  


  

    
Ethernet's binary (exponential) backoff
Lab

    
After the m-th collision in a row, Ethernet picks K at random from {0, 1, …, 2m−1} and waits K × 512 bit times. More crashes mean a wider range, so carriers spread out.

    

    

    
No collisions yet. Press Collide! to see what Ethernet does.

  


  
Real-world mix: cable access (DOCSIS)
Downstream uses FDM channels broadcast by the CMTS. Upstream mixes TDM (slots assigned by a MAP frame) with random access (contention slots with binary backoff) for requesting slots. All three families in one network.

Two kinds of address, and ARP
Every interface has a 32-bit IP address and a 48-bit MAC address. They do different jobs.


  

    
IP address · e.g. 137.196.7.23
Like a postal address
Network layer. Depends on the subnet you live in, so it changes when you move. Used for routing across the world.

    
MAC address · e.g. 1A-2F-BB-76-09-AD
Like a national ID number
Link layer. Burned into the NIC's ROM (sometimes software-settable). Flat and portable: it stays the same wherever you plug in. IEEE hands blocks to manufacturers so every one is unique. Used only to reach a neighbour on the same subnet.

  

  
Broadcast address FF-FF-FF-FF-FF-FF is like writing "To every resident on this street". Every NIC on the LAN opens it.


  

    
ARP: "Who lives at this address?"
Lab

    
You are house A. To send a frame you need the neighbour's MAC, but you only know their IP. ARP shouts the question to the whole street, the owner answers, and you save it in your ARP table for 20 minutes (sped up here: 1 second = 1 minute).

Ethernet: the most common envelope
The first widely used LAN, still dominant: cheap, simple, and it kept up with the speed race from 10 Mbps to 400 Gbps. Co-inventor Bob Metcalfe won the 2022 Turing Award.


  

    
Open the Ethernet envelope
Lab

    
Tap each part of the frame.

    

    

  


  

    
Connectionless & unreliable
No handshake before sending, and no ACK or NAK back. It's ordinary post, not registered mail. If a frame is dropped, only a higher layer like TCP will notice and resend.

    
Topology then and now
Bus (to mid-90s): one coax cable, everyone in the same collision domain. Switched (today): a switch in the middle, each spoke its own link, so nodes never collide.

    
CSMA/CD in Ethernet
Sense the channel. Idle: send. Busy: wait until idle. Collision while sending: abort, send a jam signal, then do binary backoff (see stop 3).

    
802.3 standards
Many physical media (copper, fiber: 100BASE-TX, 100BASE-FX, …) and speeds, but one common MAC protocol and frame format.

Switches: the self-learning sorting room
A switch reads each frame's destination MAC and sends it only where it needs to go. Hosts don't know it's there, and nobody configures it: it is plug-and-play and learns by watching return addresses.

The rule, step by step
    
1. Record the sender's MAC and the port it came in on. 2. Look up the destination MAC. 3. Found it? If it's on the same port the frame came from, drop it; otherwise forward on that one port. Not found? Flood: send on every port except the one it arrived on. Switches chained together learn the same way.


  
Why switches beat a shared bus
Each host has its own link to the switch, the switch buffers frames, and links are full duplex. Each link is its own collision domain, so A→A′ and B→B′ can happen at the same time. Two hosts sending to the same destination still have to queue.

VLANs: separate mailbags in one building
In one big LAN, every broadcast (ARP, DHCP, unknown MAC) reaches everyone. That hurts efficiency, security and privacy. And if a CS person moves to the EE office, they still want to be on the CS network.

Port-based VLAN
Switch software groups ports. Frames from ports in one VLAN only reach ports in the same VLAN. Membership can change on the fly, and VLANs can also be defined by MAC address. Traffic between VLANs goes through a router.

    
Trunk ports and 802.1Q
To stretch a VLAN across several switches, a trunk port carries frames for every VLAN. Each frame gets a tag saying which VLAN it belongs to:

EVPN / VXLAN
Carry Ethernet frames inside IP datagrams between sites, so one layer-2 network can be "stretched" over a layer-3 network (RFC 7348). An envelope mailed inside another envelope.







  
Stop8

    
MPLS express labels and data-center mega-hubs
MPLS sticks a short fixed-length label on each packet. Label-switched routers forward by the label alone, without reading the IP address, much like a coloured "Route 7 express" sticker sorting mail faster than reading full addresses.


  

    
IP routing vs MPLS routing
Lab

    
Two flows (from A and from B) go to D. Plain IP picks the path by destination only. MPLS can send them different ways, and switch to a backup path instantly when a link fails.

Signaling: OSPF and IS-IS are extended to flood link bandwidth info, and the entry router uses RSVP-TE to set up labels downstream. Each router keeps an MPLS table: in-label → out-label, out-interface.


  
Data centers: the mega sorting hub

  
Tens to hundreds of thousands of servers packed close together (Amazon, YouTube, Google). The hard parts: huge numbers of clients, reliability, and balancing load without bottlenecks.

  

    
Route a request through the hub
Lab

    
Rich interconnection gives many paths between racks: more throughput and more redundancy. Each request may take a different route.

    

    

    
Requests enter from the Internet at the load balancer.

  

  

    
Load balancer
Application-layer routing: takes client requests, picks a server, and hides the inside of the data center.

    
Top-of-rack (TOR)
One switch per rack of 20–40 server blades, 100G–400G Ethernet to each blade. Tier-2 switches each connect about 16 TORs.

    
Protocol tricks
RoCE (remote DMA over Ethernet), ECN-based congestion control (DCTCP, DCQCN), SDN everywhere (Google's Orion), and placing related services in the same rack.
